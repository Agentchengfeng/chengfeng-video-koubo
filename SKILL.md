# chengfeng-videocut-koubo

This is the installer package for `chengfeng-videocut-koubo`（成峰剪口播）.

Install it with:

```sh
npx -y github:Agentchengfeng/chengfeng-videocut-koubo install
```

The installed skill cuts a self-recorded Chinese voiceover: it removes slips, repeats, retakes and half-finished sentences (keeping the last complete take), shortens long pauses, re-checks the cut audio with speech recognition, and produces a review page where every cut can be played back.
